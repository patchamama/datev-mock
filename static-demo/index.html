DATEV Mock — Static Demo GitHub repo
This is a static, read-only snapshot — not the real mock

Everything below is pre-generated data served as plain files (GitHub Pages has no server compute), for a small, fixed demo id set:

  • Clients: demo-client-1, demo-client-2
  • Fiscal years (each applies to both clients): demo-fy-2024, demo-fy-2025
  • Cost system: demo-cost-system-1

JSON and XML are separate static files here — there's no live Accept-header content negotiation like the real mock has, since there's no request to negotiate on. There are also no write endpoints (impossible on static hosting by definition), and the write-derived resources (cost-center properties, cost sequences, cost accounting records, various addresses) are excluded — a fresh snapshot would only ever show them as empty arrays, which teaches nothing and just adds clutter.

To run the real, full dynamic mock locally — any client/fiscal-year id you want, actual writes, a live request log, the admin UI, Swagger — install it with the one-line installer from this repo's README “Install and run (one line)” section, then point at https://127.0.0.1:58452 (self-signed HTTPS certificate — accept the browser warning once). A few endpoints to try once it's running:

  • https://127.0.0.1:58452/datev/api/master-data/v1/clients
  • https://127.0.0.1:58452/admin — settings, CRUD, live request log
  • https://127.0.0.1:58452/docs — Swagger UI
